# DrivePro - Driving School Management System

Production-ready static site for Cloudflare Pages.

## Quick Deploy

```bash
npm install
npm run deploy
```

## Project Files

- **index.html** - Main application shell
- **admin.js** - Admin panel functionality
- **instructor.js** - Instructor dashboard
- **owner.js** - Owner portal  
- **firebase-messaging-sw.js** - Service Worker for notifications
- **_headers** - Security headers (CSP, CORS, etc.)
- **_redirects** - SPA routing configuration
- **wrangler.toml** - Cloudflare Pages configuration
